# Arya language identity

The Arya mark is a geometric **A** with a turquoise connecting span. The two structural legs suggest different language ecosystems; the bridge links them through one readable language.

- `arya-logo.png`: transparent primary mark for light surfaces.
- `arya-logo-dark.png`: transparent companion mark with lighter structural legs for dark surfaces.
- `arya-mark.svg` and `arya-mark-dark.svg`: clean vector companions for light/dark interfaces and small file icons.
- `arya-mark-monochrome.svg`: one-color vector companion using `currentColor`.
- Use the name **Arya** for the language, **Arya Lang** where a descriptive label helps, and **AryaCode** for the existing IDE.

Preserve the mark's proportions and leave clear space around it. The PNG artwork was generated with imagegen. The SVG companions were constructed separately in code from the geometric A-and-bridge motif; they are deliberately clean small-size artwork, not an exact trace of the raster pixels. Use the SVG companions for file icons and scalable branding, and the PNG versions where a raster image is required. AryaCode's existing application icon and identity are separate.

The assets were created with the built-in imagegen tool. The prompts are saved in `prompts.txt` for future iteration.
