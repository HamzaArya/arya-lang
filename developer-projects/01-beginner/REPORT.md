# 01-beginner developer track

This track is a simulated skill level, implemented and tested with the current native Arya compiler. It contains three distinct local applications:

- [Expense Ledger](cli-expenses/README.md): CLI. [Work report](cli-expenses/REPORT.md).
- [Study Planner](gui-study-planner/README.md): GUI. [Work report](gui-study-planner/REPORT.md).
- [Pocket Notes API](service-notes/README.md): service. [Work report](service-notes/REPORT.md).

The shared learning path was API discovery, implementation, release compilation, black-box tests, error correction and rerun. Detailed actual friction and results are in each project report. No project was abandoned. Final results are recorded in `results.json`; browser interaction evidence is maintained by root integration.
