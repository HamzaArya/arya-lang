# Retired native status mirrors

These files preserve the exact former contents of `docs/feature-status.json` and
`docs/release-status.json`. Their relative paths are historical and were resolved
from `docs/`; they are not active configuration in this archive directory.

The authoritative current inventory, version and qualified platforms are in
[`native/manifest.json`](../../../native/manifest.json). Immutable publication
transactions elsewhere were not changed by this consolidation.
