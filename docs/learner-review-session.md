# Learner session record

Copy this template for each real participant. Keep unnecessary personal details
out of the record. Follow [the observer protocol](community-review.md) and supply
[the participant exercise](../fixtures/examples/learner-review/README.md). A blank
record is preparation and must not be counted as a completed session.

```text
Session ID:
Participant ID:
Date / observer:
Observation consent:
Prior experience / preferred language (optional):
Compiler and creator versions:
Archive SHA-256 values:
Source-manifest SHA-256 / documentation revision:
OS / architecture / Node / Python / editor and extension versions:
Start time:
Time to first successful output:

Task: install | report | module | JS interop | diagnostic repair | rename | mapped failure | Python
Status: completed | assisted | blocked | skipped | declined
Elapsed time:
Prediction / explanation:
Commands and actual output:
Difficulty (quote only with consent):
Help requested / intervention:
Recovery and retest:
Issue ID / minimal reproducer:

Repeat the task block for each attempted task.

Participant's closing feedback:
Observer's proposed fix (separate from observed facts):
Unresolved issues:
```

Aggregate actual sessions by task: attempted count, independent completions,
assisted completions, blockers and skips. Include the denominator for each rate.
Prioritize reproducible blockers and repeated assisted tasks. Link fixes to the
session/issue and repeat the affected task with a participant before claiming a
learning improvement. Keep automated package results in the qualification record.
