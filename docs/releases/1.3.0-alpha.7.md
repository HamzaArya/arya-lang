# 1.3.0-alpha.7 — business application qualification candidate

Unpublished local successor to retained alpha.5 and alpha.6 archives. Includes
[the business APIs and tools](../business-applications.md) and alpha.6's relocation
fix. Also rejects scalar rest-parameter annotations and infers unannotated rest
parameters as arrays, so emitted declarations match runtime calling behavior.
Use `...values: number[]`, not `...values: number`. Existing unannotated runtime
semantics are unchanged. This is an opt-in static-check correction.

Earlier archives remain frozen. [Phase and package evidence](../business-applications-plan.md)
identify the exact recorded working-tree snapshot and qualification limits.
No public/stable release, deployment or installer qualification is declared.
