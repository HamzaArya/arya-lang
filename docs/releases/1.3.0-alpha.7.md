# 1.3.0-alpha.7 — business application preview

Published to npm's **next** channel on 11 November 2026. Arya remains experimental.
Install the exact compiler with `npm install --save-exact arya-language@1.3.0-alpha.7`;
start a project with `npm create arya-language@1.3.0-alpha.7 my-app`.
The `latest` tag remains on 1.2.0-alpha.4 for both packages.

Includes [business APIs and tools](../../compat/node/docs/business-applications.md): isolated runtime
host bindings, optional static types and declarations, decimal strings, explicit
dates and time zones, bounded asynchronous work, workspace editor tools, formatting,
linting, incremental project builds, and an esbuild adapter. This revision also
rejects scalar rest annotations and infers unannotated rest parameters as arrays.
Use `...values: number[]`, not `...values: number`.

The Marketplace prerelease package is extension **1.3.2**, carrying compiler
**1.3.0-alpha.7**. The frozen npm/offline VSIX retains extension version **1.3.0**.
Runtime and editor code are identical between those distributions; Marketplace
metadata and README are updated separately. AryaCode's embedded compiler remains
separately pinned.

See the [publication record](1.3.0-alpha.7-publication.json),
[original source inventory](1.3.0-alpha.7-evidence/SOURCE-MANIFEST.json),
[build normalization](1.3.0-alpha.7-evidence/build-normalization.json), and
[prepublication qualification](1.3.0-alpha.7-evidence/qualification.json).
Earlier archives remain frozen. Prepublication records retain their historical
unpublished status. Current publication status is recorded separately.

Local qualification includes 273 passing tests and four optional skips on Node 24,
Node 22 package checks, browser checks, VS Code/AryaCode extension hosts, and Ledger
preview integration tests. GitHub qualification results are linked in the publication
record. Docker, Ledger Electron installers, signing, and native installer runners
remain outside this preview's qualification. No stable release is declared.
