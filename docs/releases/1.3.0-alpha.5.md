# 1.3.0-alpha.5 — business application candidate

Unpublished local candidate, 11 November 2026. Node.js 22.15+ remains required.
The recorded public npm baseline is still 1.2.0-alpha.4.

Implements runtime name isolation, exact decimal strings, strict date/instant/zone
utilities, bounded async iteration, optional static annotations and checked module
exports, declaration output, conservative formatting/linting, top-level parser
recovery, snapshot-aware references/rename/signatures, incremental compilation,
Node test entry points and an esbuild adapter. A separate Ledger integration builds
a fixed Arya bank CSV mapping and previews it through the existing import UI.

Read the [API contracts, examples, error behavior and limitations](../business-applications.md)
and [phase evidence](../business-applications-plan.md). Existing unannotated modules
remain dynamic. Rebuild generated output; host-name shadowing no longer breaks
injected helpers. No currency/tax policy is introduced in the language library.
Annotations are erased and do not replace runtime input validation. Unsupported
type/declaration constructs, closed-file editor discovery and interactive editor
qualification remain explicit limitations. This is not a stable or public release.
