# Arya 1.1.0-alpha.1 — native compilation and self-hosting

This experimental preview adds a C11 native target and an Arya-written native compiler. The default npm CLI still supports the existing JavaScript/npm/Python execution profile. This release does not declare the outstanding stable 1.0/community gates complete.

Native programs build to machine code and run without Node.js, Python, or a C compiler. Building programs requires a C11 toolchain and platform SDK. Use `arya build main.arya --target native -o build/main` through npm, or the release's `arya-native build main.arya -o build/main` standalone compiler.

The native profile includes lexical scopes, functions/closures, recursion, lists/records, modules/live exports, exceptions, source-positioned errors, automatic cycle-collecting memory management, numeric specialization, and standard console, file, math, process, and path libraries. New `use std "io" as io` syntax is contextual; std remains a valid identifier.

The compiler in bootstrap/compiler.arya implements its lexer, parser, resolver, module graph, C emitter, optimization pass, and CLI in Arya. Three-generation bootstrap verification compares generated C and runs native conformance/calculator programs. The standalone compiler does not invoke Node or the TypeScript compiler.

AryaCode adds the `arya.language.target` setting; select native for normal Run/Build and profile-specific diagnostics. The portable extension offers aryaLanguage.target/ccPath. The native language service/API is available from `arya-language/native`.

See the [native guide](../arya-native.md) and [native specification](../arya-native-specification.md) for exact commands, supported APIs, limits, and profile differences. Native execution does not supply npm/Python imports, a GUI toolkit, async/threads, a general C FFI, Windows native support, or source-level interactive debugging. Numeric benchmark results describe measured workloads, not universal C/Rust performance.

Qualification logs, compiler/runtime source hashes, bootstrap evidence, native benchmark samples, platform matrix results, and archive checksums accompany the candidate artifacts. Only actual passing jobs qualify a platform. Existing JS/editor/interop regression checks remain required. The package and native archives retain Apache-2.0, NOTICE, and third-party notices.
