# 1.3.0-alpha.6 — reviewed business application candidate

Unpublished successor to the retained alpha.5 local artifact. Includes the
[business application APIs and tools](../business-applications.md), plus removal
of unused source-directory arguments for standard libraries that do not consume
them. Path-aware web/Python imports retain their documented source roots.
Application bundlers can now remove source comments while keeping relative maps
without retaining an unused absolute checkout path in decimal/date imports.

Alpha.5 archive bytes/hashes remain frozen. Rebuild and pin the new artifact;
existing language call forms are unchanged. See [phase and package evidence](../business-applications-plan.md).
No stable/public release, deployment or broad platform qualification is declared.
