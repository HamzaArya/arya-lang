# 1.3.0-alpha.11 — exact accounting prototype

This unpublished source candidate retains the alpha.10 compiler/editor improvements
and adds an independently packaged invoice and ledger calculation library. The
existing language syntax, JavaScript emitter, Node runtime and decimal library
remain the application baseline.

The library uses exact scaled integers, explicit rounding and checked line bounds.
Reusable batches avoid repeated parsing. An optional Node-API C++ kernel accelerates
eligible calculations; portable BigInt remains available. The standalone runtime
package carries no npm runtime dependencies or automatic installation compiler step.

Read the [API and limits](../accounting-engine.md), [milestone evidence](../../compat/node/docs/accounting-milestone.md),
[architecture audit](../../compat/node/docs/architecture-audit.md), [target architecture](../../compat/node/docs/architecture-target.md),
and [staged roadmap](../../compat/node/docs/implementation-roadmap.md).

This is not a standalone native compiler or production financial certification.
Typed IR, independent executables, ISO currency data, FX and the broader accounting
libraries require subsequent verified milestones. No package or editor publication
is performed by this candidate work. Published alpha.9 and retained alpha.10
artifacts keep their existing identities.
