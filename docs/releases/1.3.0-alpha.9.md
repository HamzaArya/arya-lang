# Arya 1.3.0-alpha.9 reliability preview

Published on **11 November 2026** to npm’s **`next`** channel. Compiler and creator are **1.3.0-alpha.9**; the published Marketplace/offline extension is **1.3.4**. `latest` remains 1.2.0-alpha.4. See the [verified publication record](1.3.0-alpha.9-publication.json).

## Changes

- Correct optional type inference for function fallthrough, required positional
  arguments after defaults, typed list/call spreads and try/catch/finally completion.
  Regression tests compare runtime values and generated declaration contracts.
- Preserve the existing decimal/datetime standard-library type improvements.
- Refresh open-document dependency diagnostics on open/change/close and share
  workspace analyses across consumers.
- Refuse exported-symbol rename in editors when unopened callers cannot be covered.
  The explicit snapshot API keeps its supplied-document contract.
- Recover trailing-member completion and bounded unfinished end-of-file calls for
  signature help. General parser recovery and closed-file indexing remain future work.
- Use the existing 256px Arya mark as the Marketplace listing icon.
- Select extension version independently with `aryaEditorVersion`, validate it in
  the release audit, and report both language/extension identities in editor status.
- Align active setup guides with published alpha.9 and add a [first-use and mixed-JavaScript path](../getting-started.md).
- Use native canonical filesystem paths consistently for web static-file containment,
  including Windows short-path aliases, and shut down test children before deleting
  their working directories. A regression reproduces the previous 404 locally.
- Keep local-only npm fixtures and installed-archive checks explicitly offline.
- Retain the earlier stabilization changes to CI, LF checkout policy, bounded TAP
  testing, stable-package auditing and packaging dependencies.

## Migration

Unannotated programs keep dynamic semantics. Annotated programs previously accepted
with a missing return/argument may now report an error. Return a value on every
path, include undefined when it is intentional, and supply required positional
arguments explicitly. Unknown-length spreads cannot guarantee required arguments;
use an explicit prefix or a rest-only boundary. Rebuild generated JavaScript and
declarations. No new keyword or general syntax feature is introduced.

The extension's numeric version identifies editor packaging; `aryaLanguageVersion`
identifies the compiler. Use [candidate setup](../../compat/node/docs/node-runtime.md#try-the-candidate)
and a matching alpha.9 archive. Install the exact published alpha.9 compiler for these fixes.
