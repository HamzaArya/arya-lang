# Read the code at a glance

**Arya Dark** and **Arya Light** use a calm palette with distinct colors for keywords, functions, parameters, imports, constants, properties, strings, and numbers.

Your current theme also works. Semantic highlighting uses Arya's lexical bindings, so a shadowed parameter is identified correctly and words inside comments/strings keep their original colors.

CSS and JavaScript inside literal view blocks retain their embedded language scopes. Editor analysis never executes Python, imports, or your application.
