# A small beginning

Use **Arya: Open Editor Tour** for an example with UI components, functions, parameters, state, and safe access.

Save it as `main.arya` in your project. In a trusted workspace, use **Arya: Run File**, or run `npx --no-install arya run main.arya` with a project-local compiler.

AryaCode keeps its built-in execution commands. This companion extension adds appearance and semantic colors without duplicating its diagnostics or Run controls.
