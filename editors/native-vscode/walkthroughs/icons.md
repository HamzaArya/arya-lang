# Arya files, easy to recognize

The extension registers `.arya` and ships light/dark versions of the Arya mark.

Choose **Arya: Enable File Icons** to select **Arya File Icons**. It also includes simple icons for JavaScript, TypeScript, Python, JSON, HTML, CSS, Markdown, and SQL.

You can keep an existing icon theme. That theme controls whether it uses the language's fallback icon. Change themes through **Preferences: File Icon Theme** whenever you like.
