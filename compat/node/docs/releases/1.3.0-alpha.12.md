# 1.3.0-alpha.12 — native scalar executable preview

This unpublished candidate adds verified typed IR and LLVM code generation for a
bounded Arya subset through `arya native` and `arya-language/native-preview`.
Clang compiles and links real host executables, independent of Node/Python at run
time. The frontend itself still uses Node. Existing Node workflows and alpha.11
accounting contracts remain available.

Read the [native preview contract](../native-preview.md),
[milestone evidence](../native-milestone.md), [architecture](../architecture-target.md)
and [remaining roadmap](../implementation-roadmap.md). This is not a general native
runtime or production backend selection. Prior artifacts remain immutable; no
publication is performed by this work.
