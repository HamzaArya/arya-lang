# Native calculator engine contract

Standalone Arya engines; root supplies real AppKit calculator face (editable expression display, large result, keypad, Enter, Clear/Backspace, native setting selectors, optional memory keys, history table/export, optional worksheet dialogs). No HTML, HTTP, WebKit or Python/Node runtime. Root builds .app bundles with native-calculators/build.py. Own your project directory only; preserve previous apps/compiler.

main.arya receives args[0]=command, args[1]=JSON body string. DATA_FILE absolute existing-parent path (host uses Application Support/Arya Native/<unique-id>/data.json). Every body has view:'history'. Validate before mutating data. Exactly one JSON line stdout: success {ok:true,message:'',result:'printable number/expression',memory:'0',rows:[{id,expression,result,kind,time,details}],summary:'...'}; error {ok:false,message:'human explanation'} with exit0. Rows are flat and newest first; bound history to latest100 entries, input complexity/length, precision and stored bytes. Invalid/corrupt data must fail visibly without resetting. Atomic save; failed writes preserve existing state. list reads current state without creating file. Store sufficient lastResult+memory to survive new process per operation.

Required commands: list; calculate({expression:'...', plus calculator options}); clear-history. Default result:'0'. Optional memory (ui calculator.memory:true): memory-store/add/subtract take body.value (currentresult); memory-clear; memory-recall (response.result must be recalled memory; host puts that into expression). Arithmetic semantics of memory match your calculator and need error tests. Rejected input must not change persisted bytes.

ui.json still includes id,name,subtitle,views:[{id:'history',label:'Calculation history',columns:[{key:'expression',label:'Calculation',width:350},{key:'result',label:'Result',width:240},{key:'kind',label:'Kind',width:120}]}], actions:[...] for optional extra native worksheet dialogs with field schema below. Unique ids start calc- e.g calc-basic.

Add calculator:{placeholder:'Example: 12 + 7',memory:false,keys:[['7','8','9','/'],['4','5','6','*'],['1','2','3','-'],['0','.','(',')']],options:[]}.
Keys are insertion strings (ASCII tokens, e.g 'sqrt(', 'sin(', '0x', 'AND'); native host appends/ inserts at cursor with no arithmetic itself. Host always provides separate Clear, Backspace, = buttons; include '+' in chosen keys. Options:[{key:'angle',label:'Angle',default:'deg',choices:[{value:'deg',label:'Degrees'},{value:'rad',label:'Radians'}]}]. All options supplied as strings in calculation and worksheet calls. Keep keypad <=6 columns, <=6 rows; put uncommon functions in docs/placeholder or extra native worksheet actions.

Optional worksheet actions:[{label:'Loan payment',command:'loan',view:'history',selection:false,fields:[{key:'principal',label:'Principal',type:'text',required:true},{key:'term',label:'Months',type:'text',default:'12'}]}]. Field types text/multiline/choice; choice choices records {value,label}. No worksheet needs selected row. Worksheet success returns same snapshot and a useful result/message, history details. Do not use eval or execute supplied code; implement explicit parsers with finite grammar and resource limits. Root can adapt keys for each developer skill level.

Each app: main.arya, ui.json, smoke.py (argv1 compiled binary; Pythonstdlib reference oracle/testing only), README.md features/example expressions/semantics/limits, REPORT.md actual work/problems/fixes/abandonment. Check/build with ../../bin/arya, output .build/worker. Test real binaries using isolated DATA_FILE and separate process each call. Include numerical reference results, precedence/unary cases if supported, dividezero/nonfinite/invalid, persistence, corrupt data, failed-write preservation. No invented humanparticipants or errors. Do not change shared files; notify root of protocol needs. Root packages all final apps, verifies GUI, documents source/native boundary.
